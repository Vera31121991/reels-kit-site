Политика конфиденциальности

Эта политика описывает работу приложения reels-kit с данными Google и YouTube. Она относится к локальному приложению для личного использования владельцем, а не к Telegram-ботам или продаже услуг.

2. Какие данные доступны приложению

reels-kit использует YouTube API Services. При подключении Google-аккаунта приложение запрашивает разрешения youtube.upload и youtube.readonly. Точный объём предоставляемого доступа показывается на экране согласия Google.

  • Идентификатор и название подключённого YouTube-канала, количество подписчиков и видео.
  • Выбранные владельцем видеофайлы, названия, описания и настройки видимости для отправки на YouTube.
  • Идентификаторы и ссылки загруженных видео, время и результат загрузки, сообщения об ошибках.
  • Данные публичных каналов и видео, доступные через API: названия, даты, длительность, счётчики просмотров, отметок «Нравится» и комментариев. При использовании функции чтения комментариев — публичные комментарии и сведения об их авторах, возвращаемые API.
  • Токены OAuth, необходимые для работы с разрешёнными функциями и обновления доступа.

Приложение не запрашивает и не сохраняет пароль Google. Для указанных функций не требуется доступ к Gmail, Google Диску или адресной книге.

3. Для чего используются данные

Данные используются для подключения собственного канала, загрузки выбранных роликов, выполнения заданного расписания, просмотра доступной статистики, исследования публичного контента и устранения ошибок. Операции выполняются в пределах настроек и разрешений владельца.

Данные Google не продаются, не используются для таргетированной рекламы, кредитного скоринга или обучения общих моделей искусственного интеллекта. Использование данных Google API и их передача ограничиваются описанными функциями и требованиями Google API Services User Data Policy, включая применимые требования Limited Use.

4. Где хранятся данные и кто получает доступ

Приложение работает на компьютере владельца. OAuth-токены, настройки, подготовленные материалы и журналы операций сохраняются локально. Токены хранятся в файле, поэтому доступ к папке приложения должен быть ограничен владельцем; эти файлы нельзя размещать в публичном репозитории или передавать посторонним.

Для выполнения запросов Google и YouTube получают необходимые параметры и токены доступа, а при загрузке — выбранный видеофайл и его метаданные. Видимость загруженного видео определяется настройкой публикации и правилами YouTube. Обработка на стороне Google регулируется Политикой конфиденциальности Google.

Google-токены и данные подключённого канала не передаются публичному сайту описания приложения. Отдельного сервера reels-kit для хранения этих данных нет. Если владелец самостоятельно передаёт материалы в другие сервисы, такая передача требует отдельного решения и проверки условий соответствующего сервиса.

5. Хранение и удаление

Владелец хранит локальные данные только пока они нужны для описанных функций. В текущей версии нет автоматического удаления по сроку; ненужные локальные результаты API, журналы и токены удаляются вручную. Сохранённые данные YouTube API необходимо обновлять или удалять в сроки, предусмотренные правилами YouTube API Services; их нельзя считать бессрочно актуальными.

Чтобы прекратить обработку, остановите задания приложения, отзовите доступ reels-kit в настройках безопасности Google и удалите локальные токены и сохранённые данные YouTube, включая их резервные копии. Для помощи или запроса удаления напишите v.abyshkina@gmail.com, указав канал и данные, которых касается запрос. Пароли и токены присылать не нужно.

Отзыв доступа прекращает дальнейшие разрешённые обращения к аккаунту, но сам по себе не удаляет локальные копии или уже загруженные видео. Видео на YouTube можно удалить отдельно через YouTube Studio.
