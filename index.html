reels-kit помогает ИП Липатовой Вере Владимировне готовить и размещать согласованные видеоролики на собственном YouTube-канале «Поле Веры».

Канал «Поле Веры» ↗

Приложение работает на компьютере владельца. Этот сайт содержит его описание и документы.

Возможности

От готового видео
до публикации.

  1. Подготовка

    Работа с видеофайлами, названиями и описаниями, выбранными владельцем.

  2. Загрузка

    Передача подготовленных роликов на подключённый YouTube-канал через YouTube API Services.

  3. Расписание

    Размещение подготовленных публикаций по установленному владельцем плану при работающем приложении и доступе к сети.

  4. Информация о канале

    Получение названия канала, сведений о видео и доступной статистики. Поиск публичных видео и каналов через YouTube Data API.

Доступ под контролем владельца

Подключение через Google.

Авторизация проходит на странице Google. Приложение не запрашивает пароль от Google-аккаунта. Разрешения нужны для загрузки видео и чтения данных YouTube.

Владелец выбирает контент и настройки публикации. Доступ можно отозвать в настройках Google-аккаунта.
